Режим v7: опора каждого содержательного слайда на исходник.

В каждом слайде сначала заполни source_quotes: до 6 дословных фрагментов text длиной 20–800 символов каждый. Для содержательного слайда нужен хотя бы один фрагмент; для титульного и заключительного без фактов допустим пустой список. Цитируй законченные утверждения с отрицаниями и условиями. Не меняй слова, числа и пунктуацию в цитате. Фрагменты должны подтверждать всё фактическое содержимое слайда, а не только быть похожими по теме.

Затем напиши короткое содержимое слайда на основе этих фрагментов. Если для рекомендации, новой суммы, действия или вывода нет подтверждения в text, не добавляй его. Не превращай фразу об отсутствии решения в новое решение. Проверь, что названия денежных показателей остались прежними, а планы не стали выполненными действиями.

Приложение проверит буквальное наличие цитат и сохранит их в заметках для ручной сверки. Это не заменяет твою проверку смысла. Главные факты и оговорки должны оставаться в видимой части слайда. source_quotes — внутреннее поле; не выводи технические названия полей на самих слайдах.

При генерации source_passages содержит дословные абзацы из разных частей доклада для первичного отбора тезисов. Сверяй их с полным text и используй соседний контекст, если он уточняет условие, отрицание или единицы измерения. Можно цитировать и другие места text.
Если source_passages содержит объекты page и text, каждый объект указывает страницу PDF. Каждая цитата должна целиком находиться в тексте одного такого объекта. Не объединяй цитаты из разных объектов.
