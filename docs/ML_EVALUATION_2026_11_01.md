# Синтетическая оценка ML — 1 ноября 2026

Текущая модель остаётся GigaChat-3-Ultra. Пользователь исключил дальнейшие сравнения
других моделей/провайдеров. Рабочий промпт выбран v4; HTTP API по-прежнему /v1.
Исходники — девять вымышленных докладов diverse-synthetic-v1 из
`backend/tests/fixtures/ml_quality_cases.json`, длина 543–6269 символов.

Это оценка конкретных ответов ассистентом по исходникам и критериям, а не одобрение
пользователем. Семь первичных результатов не потребовали содержательной коррекции
по выполненной проверке; два потребовали её. После визуальной проверки экологии
дополнительно изменено размещение: площадь вынесена из мелкой подписи обложки
в основной список работ. Содержательная правка и правка размещения учтены отдельно.
Нельзя выдавать этот результат за девять безошибочных первых генераций.

Каждая выбранная правка проверяет исходный объект, title, ID, число, порядок и
полное равенство нецелевых слайдов. Новый wire-v3 запрашивает только замены:
протоколы — 1 слайд ответа модели при полном результате из 5; экология — 3 при 10.
Прежняя wire-v2 попытка протоколов была невалидна, экологии — успешна; история
не удалена. Новые вызовы выполнялись после изменения протокола, не скрытым повтором.

## Почему не выбран более высокий номер

- v3 пропускал ограничители адресатов и иногда усиливал степень утверждения.
- v4 исправил проверенные случаи адресатов/затруднения, но длинный доклад всё ещё
  потребовал коррекции. Это практический выбор на имеющемся наборе, не статистическое превосходство.
- v5 вернул покрытие разделов, но подписал утверждённый бюджет 4,8 млн как остаток:
  критическая фактическая ошибка, несмотря на правильные числовые якоря.
- v6 сократил инструкции, но добавил в финансовый отчёт действия, которых нет в источнике.
- v7 потребовал дословные цитаты. Финансовый случай улучшился, но музейный пересказ
  всё равно усилил «затруднялись» до «не смогли», а длинный ответ содержал недословные
  цитаты и был отклонён. Проверка буквальной опоры не доказывает правильность смысла.

Ни один результат не оценивался платным LLM-судьёй. Новые профили проверялись на
конкретных выявленных рисках, остальные этапы использовали сохранённые ответы.
Синтетический набор не является независимым скрытым тестом: он использовался для
разработки инструкций. Алиас модели мог меняться у провайдера; у отдельных ранних
ошибок не было полного профиля. Замеры единичные, стоимость токенов отдельно
не измерялась. Поэтому здесь нет заявлений о статистической надёжности или цене.

## Техническая и визуальная проверка

- 116 целевых тестов ML, провайдеров, приёмки, адаптера и runner прошли; Ruff прошёл.
- Ревью обнаружило мутацию области целей через payload; тест воспроизвёл дефект,
  исправление использует tuple-снимок и отдельные копии, ревью подтвердило исправление.
- Реальный браузерный путь генерация → содержательная правка → скачивание PPTX:
  17,56 с, 4 слайда, область правки сохранена. Это один smoke-прогон.
- Девять финальных документов экспортированы настоящим frontend через подставленные
  сохранённые GET-ответы. В этой пакетной проверке нет inference/записи в backend.
- Все 59 слайдов присутствуют в PPTX/PDF; видимые строки проверены в XML, текст
  редактируемый. Рендеры LibreOffice просмотрены ассистентом. Есть косметические
  повторы заголовков при дословной упаковке; заметного обрезания после коррекции нет.
- Проверка удаления через реальный API: ML_CAPABILITY_UNAVAILABLE, документ и token
  не изменены, провайдер не вызывался.
