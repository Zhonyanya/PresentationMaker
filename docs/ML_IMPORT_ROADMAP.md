# Следующая сессия по импорту докладов

Цель сессии — подготовить импорт PDF и DOCX к приёмке на реальных документах и сократить число случаев, когда содержимое таблиц или подписей теряет структуру.

## 1. Зафиксировать состояние ветки `ml`

- Сверить локальные изменения импорта с веткой `ml`. Проверить, что общий экран импорта принимает PDF и DOCX, показывает предпросмотр и скачивает PPTX.
- Добавить в репозиторий небольшой синтетический DOCX с PNG, JPEG, подписью и длинной таблицей. Использовать его для воспроизводимой проверки пути от загрузки до экспортированного файла.

## 2. Сохранить структуру таблиц и подписи из DOCX

- Проверить перенос объединённых ячеек в редактируемую таблицу PowerPoint. Начать с прямоугольной сетки с горизонтальными и вертикальными объединениями. При невозможности сохранить структуру оставить текстовый перенос с пояснением в интерфейсе.
- Учитывать стиль Word «Подпись» рядом с рисунком или таблицей. Сохранить порядок блоков и поддержать подписи без ручной нумерации.
- Убедиться, что при разбиении длинной таблицы повторяется размеченная шапка, а каждая строка данных переносится один раз.

## 3. Проверить результат на стенде

- Прогнать синтетический DOCX и PDF через предпросмотр и экспорт. Проверить в PowerPoint подписи, пропорции иллюстраций, редактируемость ячеек и отсутствие обрезки.
- Локально проверить реальные доклады. Сравнить исходные страницы с иллюстрациями, таблицами и ссылками на страницы в PPTX. Реальные документы и выгруженные презентации хранить вне Git.
- Запускать тесты только для изменённых сценариев. Для проверки импорта и экспорта использовать локальные данные без вызовов модели.
